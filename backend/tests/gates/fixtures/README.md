# กรณีที่ต้องถูกปฏิเสธ (RQ-12)

ไฟล์ในโฟลเดอร์นี้ **ผิดกฎโดยเจตนา** และถูกกันออกจากด่านตรวจปกติ
(`extend-exclude` ของ ruff, `exclude` ของ mypy)

เทสต์ใน `tests/gates/` รันเครื่องมือกับไฟล์เหล่านี้ และต้องพิสูจน์สามอย่างทุกครั้ง:

1. **แดงเพราะกฎที่ตั้งใจทดสอบ** ไม่ใช่เพราะเครื่องมือรันไม่ได้
2. **กรณีที่ถูกต้องคู่กันต้องผ่าน** ภายใต้ชุดตั้งค่าเดียวกัน
3. รันด้วยชุดตั้งค่าเดียวกับด่านจริง

**ห้ามลบโฟลเดอร์นี้** ถ้าลบ จะไม่มีอะไรพิสูจน์ว่าด่านตรวจยังทำงาน
