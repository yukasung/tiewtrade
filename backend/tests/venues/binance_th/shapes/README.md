# รูปร่างของคำตอบที่ยังไม่มีคำตอบจริงให้บันทึก

**ต่างจาก `recorded/` โดยเจตนา** — ที่นั่นเก็บ **คำตอบจริง** จาก endpoint สาธารณะ
ที่เจ้าของอนุมัติ และมีด่านบังคับว่าห้ามมีคำรับรองหรือข้อมูลของใครอยู่ในนั้น

ที่นี่เก็บคำตอบของ endpoint ที่ **ต้องลงลายเซ็น** ซึ่งบันทึกคำตอบจริงไม่ได้
เพราะคำตอบจริงคือยอดเงินของเจ้าของ · **ชื่อช่องมาจากการเรียกจริง** เมื่อ 2026-10-04
(F-07 NC-16) ส่วนค่าในนั้นแต่งขึ้นทั้งหมด
