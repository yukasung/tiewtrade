# specs/

เอกสารทั้งหมดของโปรเจกต์อยู่ในโฟลเดอร์นี้ ไม่มี `docs/`

```
specs/
├── README.md        ← ไฟล์นี้
├── mission.md       ← ผลิตภัณฑ์คืออะไร ใครใช้ ไม่ทำอะไร
├── tech-stack.md    ← เลือกเทคโนโลยีอะไร เพราะอะไร
├── roadmap.md       ← งานทั้งหมดและสถานะ
├── standards/       ← กฎที่ต้องทำตามเวลาเขียนโค้ด
└── features/        ← spec ของแต่ละงาน
```

## อ่านตามลำดับนี้ถ้าเพิ่งเข้ามาใหม่

1. `mission.md` — เข้าใจว่ากำลังสร้างอะไร
2. `standards/trading-safety.md` — กฎที่สำคัญที่สุดในโปรเจกต์นี้
3. `tech-stack.md` — เครื่องมือที่ใช้
4. `roadmap.md` — งานตอนนี้อยู่ตรงไหน
5. `standards/` ที่เหลือ — อ่านตอนจะเขียนโค้ดส่วนนั้น

## สถานะเอกสาร

**ทุกไฟล์ยังเป็น Proposed** ยังไม่มีอะไรได้รับอนุมัติ และยังไม่มีโค้ด

## กฎ

- ถ้าโค้ดกับ spec ขัดกัน **ให้หยุดแล้วถามเจ้าของ**
- ข้อที่ยังไม่ตัดสิน อยู่ใน `mission.md` หัวข้อ 9 — ห้ามเดาแทน
